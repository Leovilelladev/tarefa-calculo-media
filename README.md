# Cálculo de Média

Programa Java que lê quatro notas, calcula a média aritmética e informa a situação do aluno.

## Como executar

Com o Java instalado, execute no terminal, a partir da raiz do projeto:

```bash
javac -d out tarefa_calculo_media/CalculoMedia.java
java -cp out CalculoMedia
```

Digite as quatro notas quando solicitado.

## Resultado

Média maior ou igual a 7: **Aprovado**

Média maior ou igual a 5 e menor que 7: **Aprovado de recuperação**

Média menor que 5: **Reprovado**
